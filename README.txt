سلسلة مدار - الإصدار 3
التشغيل على الكمبيوتر:
1) ثبّت Node.js 18 أو أحدث.
2) فك ضغط الملف.
3) افتح CMD/Terminal داخل مجلد المشروع.
4) نفّذ: npm install
5) ثم: npm start
6) افتح المتصفح على: http://localhost:3000
لوحة الإدارة: http://localhost:3000/admin.html
